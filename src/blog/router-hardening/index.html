Fifteen Minutes for Your Router: A Security Checklist

The router is the front door of every home and small office network. A few settings decide whether it stays locked.

Every device in your home or office reaches the internet through one box: the router. It decides what gets in, it holds the Wi‑Fi password and it tells every device which DNS server to trust. Yet most routers are set up once, on the day the technician leaves, and never looked at again.

The good news: you do not need to be a network engineer to lock it down. Set aside fifteen minutes, open the router's admin page and go through this list.

Before You Start

Find out how to reach the admin page. It is usually printed on a sticker on the router. The most common addresses are 192.168.1.1 and 192.168.178.1 (the default of FRITZ!Box routers, which also answer to fritz.box); some models use 192.168.0.1. Log in from a device connected by cable or to your own Wi‑Fi, never over the internet.

If your provider manages the router remotely, some settings may be locked. That is normal: the provider then takes care of updates, and you can still check most of the points below.

1. A Strong, Unique Admin Password

The password for the admin page is not the Wi‑Fi password. If it is still the default, or admin, change it now to a long password stored in your password manager.

Since August 2025, new wireless devices sold in the EU must meet basic security rules, including no universal default passwords. Older routers often shipped with one password for every unit, which is exactly what automated attacks try first.

2. Updates on Autopilot

Router firmware gets security fixes like any other software. Look for an option such as automatic updates and turn it on. Then check the firmware date: if your router has not received an update in years, the manufacturer has probably stopped supporting it, and replacing it is the only real fix. The same question applies to every other device at home, as what to do at end of support explains.

3. No Admin Access From the Internet

Many routers can be managed from outside, labelled remote access, remote management or internet access to the user interface. Unless you need it, switch it off. If you do need access on the road, use the router's VPN feature instead of opening the admin page to the whole internet. Our article on reaching your network safely explains the options.

4. Modern Wi‑Fi Security

  • Use WPA3, or WPA2/WPA3 mixed if older devices cannot connect otherwise. Never WEP and never an open network.
  • Disable WPS. The push‑button and PIN pairing method has had serious weaknesses, and nobody misses it.
  • Use a long Wi‑Fi password. Twelve random characters or more; it only has to be typed once per device.
  • Give guests their own network. Visitors and their devices never need access to your NAS or printer. See segmenting your home network.

5. Check What Is Open

Look for a page called port forwarding, port sharing or NAT. Every entry there is a door from the internet into a device on your network. Delete everything you do not recognise or no longer use.

Then look at UPnP (Universal Plug and Play). It lets devices open such doors on their own, which is convenient for game consoles and risky for cameras and NAS systems with outdated firmware. If nothing stops working without it, turn it off. If you need it, check the list of automatically opened ports from time to time.

6. Check the DNS Setting

Some malware changes the router's DNS servers, silently redirecting every device to fake websites. Look at the DNS setting under internet or network settings: it should be your provider's default or a resolver you chose deliberately (see DNS explained). Anything unfamiliar is a red flag.

7. Look at the Device List

The router knows every device on your network. Give the important ones recognisable names, and look for devices you cannot place. An unknown device is usually a forgotten smart plug, but sometimes it is a neighbour who knows your Wi‑Fi password, which is a good reason to change it. How to put a name to every entry is explained in who's on my Wi‑Fi.

The Checklist at a Glance

Setting Target Why
Admin password Long, unique, in a password manager Defaults are tried first by automated attacks
Firmware updates Automatic Most attacks use known, already fixed flaws
Remote management Off (use VPN instead) Keeps the admin page off the internet
Wi‑Fi security WPA3 or WPA2/WPA3, WPS off Strong encryption, no shortcut pairing
Port forwarding, UPnP Only what you need Every open port is a door
DNS servers Default or deliberately chosen Prevents silent redirection
Device list Named, nothing unknown Spots intruders and forgotten devices

For Small Businesses

Everything above applies, plus three habits:

  • Document the admin access in the company's password manager, not on a sticky note, and make sure two people can reach it.
  • Back up the router configuration after every change. Most routers can export it as a file, which turns a replacement into a ten‑minute job.
  • Plan the replacement. Put the router's end of support on the calendar like a lease expiry.

Conclusion

Most attacks on routers are not sophisticated. They try default passwords, known holes in old firmware and admin pages that should never have been reachable from the internet. A strong password, automatic updates, no remote management, modern Wi‑Fi security and a quick look at open ports close almost all of them. Fifteen minutes now, and a short check once a year, keep the front door locked.
